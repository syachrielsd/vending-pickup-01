One pickup line, spoken by a vending machine flirting with a passing human: "I've held this chocolate hostage for three weeks, but one look from you and my coil let go. Press B4, I'm all yours."

## Run it

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), reads it back, and verifies it is byte-identical, one line, and 1–200 characters.
